# PWA 圖標說明

## 📦 需要的圖標

將以下尺寸的圖標放在此目錄：

```
icon-72x72.png
icon-96x96.png
icon-128x128.png
icon-144x144.png
icon-152x152.png
icon-192x192.png
icon-384x384.png
icon-512x512.png
```

## 🎨 快速生成

1. 在瀏覽器中開啟：`../../scripts/generate-icons.html`
2. 點擊「生成圖標」
3. 點擊「下載全部」
4. 將下載的圖標放到這個目錄

## 🖼️ 設計規範

- **配色**：粉色 `#e6c4c4` 背景 + 深粉色 `#ba8c8c` 圖標
- **風格**：可愛的存錢豬
- **格式**：PNG
- **最重要**：192x192 和 512x512（必需）
